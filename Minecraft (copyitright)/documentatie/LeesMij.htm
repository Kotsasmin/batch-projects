 Met mijn launcher geniet je van de onderstaande mogelijkheden/voordelen:


  + De officiële Minecraft launcher (en Minecraft) hoeven niet te worden gekraakt.

  + Omdat er niets gekraakt wordt kunnen legitieme spelers de launcher ook gebruiken

  + Dankzij het bovenstaande feit is mijn launcher 100% compatible met je huidige mods

  + Geen DEMO-versie van 5 Minecraft-dagen (1 uur en 40 minuten echte tijd)

  + Speel alle uitgebrachte Minecraft versies, inclusief de nieuwste snapshots

  + Online speelbaar (zonder legitiem account enkel op "cracked" servers)

  + Offline en op LAN speelbaar (het spel dient tenminste één keer te zijn gestart)

  + Toepassen van MODS (spelaanpassingen) is mogelijk

  + Er kunnen meerdere "cracked" spelers worden toegevoegd

  + Niet-legitieme spelers kunnen een speler skin instellen

  + Je kunt de launcher van andere kleuren voorzien

  + Willekeurige berichten en vragen bij iedere launcher start (kan worden uitgezet)

  + Ingebouwde launcher updater (update eenvoudig naar mijn meest recente launcher versie)

  + Instelbare update notificaties (blijf op de hoogte van belangrijke wijzigingen)

  + Optionele automatische launcher updates (werking afhankelijk van User Account Control)

  + De launcher is getest onder Windows 10 (64-bit) maar zou ook onder 7/8(.1) moeten werken

  + Statistieken (je leest verderop wat dit inhoud)






 ~> START-OPTIES <~

  De mogelijke start-opties en hun betekenis zijn als volgt:


  Add Player            : Hiermee voeg je nieuwe "cracked" spelers toe aan 'launcher_profiles'

  Auth (un)blocker      : Hiermee (de)blokkeer je de Minecraft authenticatie server
                          Hierdoor is het mogelijk tussen LEGITIEME en "CRACKED" gebruikers te wisselen

  Change Colors         : Hiermee wijzig je het kleurenschema van de launcher

  Minecraft Launcher    : Hiermee start je mijn launcher en Minecraft

  Toggle Auto-updates   : Hiermee zet je automatische launcher updates uit of aan

  Toggle Notifications  : Met deze optie kun je launcher update notificaties aan- of uitzetten
                          (laat update notificaties 'aan' om geen belangrijke info te missen)

  Toggle Random Messages: Met deze optie zet je de willekeurige berichten-functie uit of aan

  Uninstall Launcher    : Hiermee verwijder je de launcher en aangemaakte snelkoppelingen van je computer

  Update Launcher       : Hiermee update je handmatig mijn launcher (zinvol wanneer update notificaties uit staan)

 ~> SPELEN OP ONLINE MINECRAFT SERVERS <~

  Naast lokaal Minecraft spelen kan er óók online worden gespeelt.
  Dit, mits de server waarmee je verbind "cracked" spelers toestaat.

  Als je tijdens het verbinden met een server de onderstaande melding krijgt,
  betekend dit dat deze server *alleen* legitieme Minecraft spelers toestaat.

  Aanmelden mislukt: Ongeldige sessie (probeer het spel en de launcher opnieuw te starten)
