# Batch Projects (Archive)

An archived collection of some of my older Batch projects. Some of these date all the way back to 2018 when I was in elementary school, written completely by hand in Windows 7 Notepad across all of the projects (long before AI tools existed).

## Projects

### [Minebatch](Minebatch/Minebatch.cmd)
A simple multi-tool I built back in elementary school in Windows 7 Notepad to run basic tasks. I loved coding and Minecraft so much back then that I put this together. It doesn't work anymore and isn't of much practical use today, but it's kept here as a piece of nostalgia.

### [Minecraft (copyitright)](<Minecraft (copyitright)>)
This project was not made by me, but by a very dear online friend (**copyitright**) who was a huge inspiration and made me love programming even more than I already did. It was a simple Minecraft launcher authentication blocker script that could add offline accounts to the official Minecraft Launcher (of course, it no longer works today). It is kept here to preserve copyitright's legacy and to remember the times when searching thousands of threads on Stack Overflow and Quora was our life instead of using an AI agent.
